## Producción técnica
| Término | Significado |
|---------|-------------|
| **ROS** | Run of Show — Minuto a minuto |
| **Escaleta** | Documento con orden de escenas, música y responsables |
| **Rider** | Listado técnico de canales, micros y backline |
| **Stage Plot** | Diagrama de tarima |
| **Set change** | Cambio de set entre eventos / entre escenas |
| **Backline** | Instrumentos de fondo (batería, bajo, amplis, teclado) |
| **Input List** | Lista de canales de entrada al mixer |
| **Cuña / Monitor** | Monitor de piso para músicos / actores |
| **Panel técnico** | Salón tras el escenario; usado como camerino para grupos musicales 6°-8° |
